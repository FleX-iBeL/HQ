# Your extensions

Everything you add to your HQ yourself goes here, one folder per extension: a connector for another mail app, a
routine of your own, a new kind of text, extra rules for calls. An update never touches this folder, and after every
update HQ checks whether anything here might clash with the new version, and tells you in plain words.

How to build one, and how to move something already built into HQ's own files into here: EXTENSIONS.md in HQ.
