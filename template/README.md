# Your workspace

This folder is yours. HQ (the app around it) is the same for everyone; this folder is what makes it your own. The installer copied it from HQ's `template/` into `workspace/`. HQ's repo never uploads it, and updating HQ never touches it. Keep it as your own private git repo if you want a backup.

Every file here starts blank and says what goes in it. **Put your own things here.** Start with `me.md`: your name, what's important to you, and what HQ should manage for you. You can also just tell Claude, in a chat or on a call, and it writes it down for you in the right place.

| File | What goes in it | Loaded |
|---|---|---|
| `CLAUDE.md` | How this folder works: what's loaded, the start of a chat, privacy, git, email | always |
| `rules.md` | How you want Claude to talk and behave. Say "rule" and it fixes this list | always, and with every message |
| `where-things-go.md` | Every kind of update has one place; the maintenance check | always |
| `me.md` | Your name, what's important to you and what isn't, what HQ should manage | always |
| `vision.md` | Your north star: the life you're working towards | always |
| `current-situation.md` | Where you stand right now: work, health, home, money, people | always |
| `challenges.md` | Everything to do, in your own priority lists | always |
| `coaching/log.md` | What happened in each conversation, your words, open commitments | always |
| `inbox.md` | New mail the hourly mail check found, waiting for your yes | always |
| `reviews/` | Weekly reviews, one file per week | when needed |
| `Jarvis VA/roadmap.md` | The status block, the job queue, and the roadmap of what HQ builds next for you | the status page and calls |
| `Jarvis VA/calls/` | Full transcripts of your calls, one file per call (not Free calls) | when needed |
| `.claude/` | The no-sending rule for email, the rules hook, the coaching skill, the mail check's commit | always |

Subfolders: add your own whenever you start something new (a project, a course, a plan), and give it a line in `where-things-go.md`.
